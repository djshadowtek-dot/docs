## Get Started in Four Steps

Follow this onboarding flow to go from a new account to a fully monitored, scalable deployment.

<Steps>
  <Step title="Create Your Account">
    Sign up at [console.cloud.google.com](https://console.cloud.google.com) and create your first project. A project is the top-level container for all resources you provision, and it is where billing, quotas, and access controls are applied.
  </Step>
  <Step title="Set Up Credentials">
    Install the `gcloud` CLI and run `gcloud auth login` to authenticate your local environment. Then run `gcloud config set project PROJECT_ID` so every subsequent command targets the correct project.
  </Step>
  <Step title="Provision a Resource">
    Create your first compute instance, storage bucket, or virtual network using the console, CLI, or API. Each resource type has a dedicated guide that covers configuration options, pricing tiers, and best practices.
  </Step>
  <Step title="Monitor and Scale">
    Enable Cloud Monitoring and Cloud Logging to collect metrics, logs, and traces from your resources. Set up autoscaling policies and alerting rules so your infrastructure responds automatically to changes in demand.
  </Step>
</Steps>
